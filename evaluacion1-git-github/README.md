
# Hackatón ADSO 2026

## Descripción
Sitio web informativo de la Hackatón ADSO 2026 del SENA CDITI de Dosquebradas.

## Objetivo
Presentar la agenda, la información de inscripción y la ubicación del evento.

## Tecnologías
- HTML5
- CSS3
- Git
- GitHub

## Agenda
El evento tendrá actividades de formación, desarrollo de soluciones y presentación de proyectos.

## Inscripción y ubicación
Los participantes podrán consultar los requisitos de inscripción y encontrar la dirección del evento.

## Enlace
Consulta el repositorio del proyecto en GitHub cuando lo publiques.
